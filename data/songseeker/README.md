# Songseeker Hitster playlists

Card lists and YouTube links from
[andygruber/songseeker-hitster-playlists](https://github.com/andygruber/songseeker-hitster-playlists),
used with the MIT license in `LICENSE`.

`scripts/import-songseeker.js` converts the CSVs into the compact
`public/hitster-cards.json` lookup used by the scanner.
